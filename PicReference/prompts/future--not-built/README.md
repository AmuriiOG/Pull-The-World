# future -- NOT BUILT

**Nothing in this folder is in the game.**

These mechanics appear on the original concept sheet but are **explicitly excluded** from
the locked prototype mechanic set:

- water
- magnets
- rescue NPC ("save them")
- ice, conveyor, teleporter, wind, timed doors

They are kept here because the concept sheet already has usable visual reference for the
first three, and throwing that away would be wasteful if any of them get picked up later.

## Rules

1. **Do not** put art generated from these prompts into store screenshots, the level
   list, trailers, or anything player-facing.
2. **Do not** treat these as a content plan. The prototype is 5 levels — see
   `../../LEVELS.md`.
3. If a mechanic here ever gets promoted into the build, move its prompt up into
   `prompts/` and add the level to `LEVELS.md` first.

Colour values for these mechanics are in `../../PALETTE.md` under "Unbuilt mechanics",
flagged as lower confidence — the source panels overlap on the sheet, so the sampler
picked up some bleed between the lava, water and magnet hues.

# output

Generated images land here, named to match the prompt that produced them:

    prompts/L3_tip-it-over_rotated.txt  ->  output/L3_tip-it-over_rotated.png

Keep that pairing. When a prompt gets revised, regenerate the image and overwrite it, so
a picture in here always corresponds to the current text of its prompt.

Images for unbuilt mechanics go in `output/future--not-built/` and are not shippable —
see `../prompts/future--not-built/README.md`.
